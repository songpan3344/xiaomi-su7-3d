# 小米 SU7 3D 交互旗舰展示网站 (Xiaomi SU7 3D Showcase)

> 基于 **Three.js**、**TypeScript** 与 **Vite** 构建的高拟真小米 SU7 3D Web 可视化交互展厅与动态试驾系统。

## 🌟 核心特性

- 🚗 **交互式 3D 轿跑模型**：按 SU7 整车长度归一化，四轮接地；当前内饰属于展示近似，尚未完成实车精细重建。
- 🔎 **分档画质与座舱观察**：自动 / 流畅 / 均衡 / 高清，支持高清屏采样、各向异性过滤、皮革与塑料细微纹理；座舱视角使用独立补光，并直接复用模型原有屏幕表面。
- 🎨 **官方 9 大全系车漆**：海湾蓝、雅灰、橄榄绿、霞光紫、熔岩橙、珍珠白、钻石黑、流星蓝、寒武岩灰，支持自定义 1600 万色自由调色。
- 🚪 **拟真车门与部件交互**：
  - 4 门独立按真实铰链物理展开/关闭，支持一键展翼与 3D 场景直接点击开闭。
  - 4 档电动升降尾翼（0° 收起 / 5° 低风阻 / 12° 巡航 / 25° 极速下压力）。
- 💡 **全车灯效与座舱系统**：水滴大灯、光环贯穿式尾灯、刹车高亮模式、双闪警示灯、64 色智能座舱环绕氛围灯。
- 🏎️ **动态公路试驾（Drive Mode）**：
  - 真实沥青标线与路灯循环移动公路。
  - 四轮随速自转，前轮转向偏转联动车身微倾。
  - 0-265 km/h 实时数字 HUD 车速表与 P/D 挡位响应。
  - 键盘 [W/A/S/D] 与触控油门/刹车踏板双端适配。
- 🔊 **纯原生 Web Audio 拟真音效**：超级电机随速啸叫声浪、高级车门关合厚重低音、智能解锁和弦、UI 按键音，零外部音频资源依赖。
- 🎥 **电影级多机位镜头**：前 45° 黄金视角、侧颜轿跑、车尾光环、运动轮毂特写、主驾沉浸座舱视角、360° 自动慢速展厅巡航。
- 📋 **车型配置与海报生成**：标准版、Pro 版、Max 版实时参数切换，一键导出专属定制高清海报，预订礼花特效。

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
本地浏览器访问：`http://localhost:8080/`

### 3. 构建生产包
```bash
npm run build
```
输出静态文件至 `dist/` 目录。

## 画质与模型素材

右下角可以切换画质和进入座舱。自动模式按设备条件选择画质，手动选择会保存在当前浏览器中。高清模式最高使用 2 倍像素比，中控屏画布为 2048 × 1280；流畅模式关闭新增内饰细节贴图，并降低阴影和纹理采样开销。大视口有总像素预算，避免显存和填充率开销无限增加。

本次保留原始 GLB 与其 1K / 2K 颜色贴图，增加程序生成的微纹理法线与分区表面贴图；这不是 4K 实车扫描素材。内饰贴图中复用的 ZEEKR 门槛字样在展示时替换为中性饰条。屏幕界面直接贴合模型原有中控与仪表表面，避免重复屏幕遮挡。仪表仅在显示车速或挡位状态变化时上传纹理，已完成动画也会从更新队列移除。

近距离展示的下一阶段应替换或重建内饰：优先提供对应年款 SU7 的授权模型、部件拆分、UV 与真实颜色 / 法线 / 粗糙度 / AO 贴图。建议保留外观和车门层级，单独接入内饰资产，并在座舱模式按需加载；当前 Atlas 识别与车门/车轮绑定仍针对本仓库原模型，换模型时必须重新验证。

代码许可说明与模型许可分开适用。原始模型 [SU7](https://sketchfab.com/3d-models/su7-7296a91633d74c6eb113010e2ed75eda) 作者为 [s1657270997](https://sketchfab.com/s1657270997)，GLB 元数据注明 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。展示端修改包含比例与朝向调整、车门/车轮拆分、材质、门槛字样处理及屏幕表面替换；原始 GLB 文件保持不变。
